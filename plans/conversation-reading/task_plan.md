# 相关会话归组与关键消息导航

## Goal

让用户从项目进入对话时少翻重复会话，更快定位请求、方案线索、失败和验证记录。2026-09-27 用户在比较研究后授权“开始做”。保持 Agent 对话阅读为主流程；2026-09-28 收口定名 AgentTraceMesh。

## Scope

- 阅读器会话列表提供可切换的“疑似相关”归组，显示理由和成员数量；全部成员可展开，完整身份与来源保留。
- 同项目或同文件不足以认定同任务；首轮仅采用有意义的标题相同等明确词法线索，泛化标题不组。
- 关键消息按需读取已有消息索引，在全文上定位后截取摘录，保留绝对位置和来源修订。首个用户请求、最后回复以及提及失败/验证/方案的消息各有原文入口；不冒称自动判断最终成功。
- 有界查询、清晰的 partial/unsupported/error，切换会话防旧响应串台；原始记录只读、检索不采样。
- 无新依赖、LLM、服务、存储迁移或强行引入第三方聚类代码。2026-09-28 授权本地提交；不推送、不替换用户正在运行的服务。

## Acceptance

全部原会话身份恰出现一次；同文件不同题不误合；跨来源同 ID 不丢；分页仍受修订约束。关键节点排除 context 但不改变绝对编号，2M/8192/2000 条之后的标记可找到，达到返回上限披露。迟到响应/409 不显示旧节点。浏览器可展开组、关归组、点节点定位正确原文，窄屏无新增溢出。

## Design

沿用 DESIGN.md 的 --panel/#fff、--bg/#f5f7fb、--text/#1f2937、--muted/#6b7280、--border/#dbe3ee、--accent/#2563eb；组件引用变量，六主题不另配色。系统字体与现有字号。左侧 native details 内保留普通会话行，右侧标题旁增加单一折叠导航，不让工具占满正文区域；键盘焦点和加载状态可见。
