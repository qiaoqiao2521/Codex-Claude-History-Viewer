# 工具借鉴与知识收尾

## Goal

让 Agent 从少量公开证据找到可借鉴工具，并在有可复用新认识时及时修订原知识页。

## Requirements

- 修复 Codex 结构化工具结果正文、错误和摘要；媒体内容不展开。
- 检索排除上下文、内部推理和未分类记录；相关摘录保留绝对消息定位。
- 提供可选无头精简结果，保留旧调用兼容、分页和修订校验。
- 知识入口返回具体操作和短段落；旧页新增触发条件也同步入口。
- 收尾 owner 在已有任务进度记录知识处理结果，并核对实际读回。
- 在现有 Codex/Claude 日志元数据保留 learning-output-style 注入与 skill 触发标记；提供修订绑定查询。
- TraceMesh 不创建 skill、不优化技能、不新建反馈数据库；后续 Agent 负责作用分析与原仓库调优。

## Scope

HistoryReader、Codex 解析、检索摘录、所选知识页和共享开发约定。沿用本地标准库、现有索引与 Markdown；不新增服务、模型或平行知识库。历史源保持只读。

## Plan

1. 复现结构化结果丢正文与检索噪声。
2. 并行修复解析和检索；增加无头精简候选。
3. 修改知识入口及收尾约定，读回受影响链接和段落。
4. 验证真实公共入口、缓存重解析与必要回归。
5. 串行审阅、隔离提交并普通推送已验证成果。

## Success

对象、文本块和字符串输出在公开 reader 中保留可解码结果；思考噪声不命中；精简结果携带可展开的真实定位；已有知识通过新触发词可发现；本任务实际完成知识修订与读回。
