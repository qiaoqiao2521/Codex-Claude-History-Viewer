# 活跃会话的固定读取与素材导出

## Goal

Codex 对话持续追加时，读取已完成索引或目标会话的有限捕获；不暂停对话，不因其他会话变化丢失整批有效更新。

## Scope

复用 SQLite WAL、现有 Codex parser、audit、公开消息过滤、脱敏、素材 Markdown。增加短读取视图、目标文件捕获、失败隔离、纯素材入口和分阶段错误回执。不新增索引系统、后台服务或模型调用，不刷新用户全库，不读真实长对话正文作测试。

## Accepted boundary

- 固定一次调用的读取视图；跨独立调用旧 revision 仍可失效。需要保留的少量素材由调用者保存导出包，不长期持有事务。
- 定点捕获保持原 source/store 根，按完整 JSONL 行确定水位。追加不扩展本次覆盖；重写、截断、替换须显式失败。
- 旧完整源绑定与 2 MiB 普通 handoff 约束保留。索引素材有独立绑定，不能把片段哈希冒充完整源修订。
- 按字符和最终 JSON 字节预算导出，公开消息之外拒绝，超限明确分包或报错。

## Ownership

根 Codex 串行整合 reader、CLI、说明与计划；read_view、capture、indexed_materials 三块分别由内部 Agent 实现。各 worker 只写分配文件，不提交，不修改共享知识。旧未跟踪验证资产保留，先核对现有任务再决定收口。

## Knowledge adopted

采用 Obsidian `Wiki/自动化开发范式与智能体协作.md` 的历史工具检索约定：保留来源与 revision，区分截断、未知与零命中。采用 SQLite 原生短事务，不自建版本存储。
