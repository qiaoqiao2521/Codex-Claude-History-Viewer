# 项目优先阅读与设置

## Goal
根据用户亲自验收截图，收敛重复检索和拥挤侧栏：选项目 → 选会话 → 阅读对话。统一设置承载偏好和来源管理。

## Scope
Linux、本地标准库后端与无构建前端；保留全局搜索、消息深链、来源修订、审计与交接。沿用蓝灰token/系统字体，响应式与键盘可用。不中断用户当前验收服务，完成隔离验收后更新运行版本。

## Plan
- [x] P1 图片/现有导航诊断与产品结构确认。
- [x] P2 轻量跨源项目会话目录与直接阅读导航。

## Acceptance
首页无查询时默认项目；一个项目内跨来源会话统一阅读；旧搜索深链不失效；主侧栏无13来源挤压或重复Keyword表单；设置持久化；420/480/1280px无页面横向溢出，键盘可打开/关闭设置并恢复焦点。

## Design
基调沿用 --bg #f5f7fb、--panel #fff、--text #1f2937、--muted #6b7280、--border #dbe3ee、--accent #2563eb。系统字体（14px正文）和等宽代码分工。首页用项目目录行；阅读页左侧项目/会话、右侧对话，设置对话框独立。左对齐，不新增营销hero/卡片看板；对话是主要内容。
