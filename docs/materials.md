# 公众号成果素材

一份素材描述一件借助 AI 完成的事，可以引用多个会话。成果声明与证据分开，默认“待核实”。

## 使用

1. 在首页“搜索历史”，或项目右侧“工作记录”里选择证据（最多 5 条，总正文 8000 字符）。
2. 在证据面板展开“整理为公众号素材”，填写标题、完成了什么，以及可选的问题、过程、经验。
3. 点击“预览素材”，核对引用、事实和隐私。
4. “下载 .md”在未配置目录时也可用；“导出到素材目录”需要显式启动配置：

```bash
python3 app.py --host 127.0.0.1 --port 8895 \
  --material-dir "$HOME/桌面/obsidian/xueyu-gongzhonghao/公众号/素材/History-Viewer"
```

目录只由启动参数决定，网页不能指定任意写入路径。使用 localhost 或 127.0.0.1 访问。

## 与公众号平台交接

素材 inbox → 人工核实与改写 → 按内容仓 CONTENT_PROTOCOL 准备带 frontmatter 的文章 → 既有 qiao-wechat 排版与草稿流程。新目录不会被发布器自动扫描，素材不等于文章，不会自动创建微信草稿或发布。

当前适用内容仓：`~/桌面/obsidian/xueyu-gongzhonghao`，公众号平台代码：`~/repo-scan/qiao-wechat`。这两个仓库保持独立。

## 保留与保护

- 文件名是素材身份 + 修订摘要，重复导出相同内容不新增副本。
- 编辑表单或来源内容变化会产生独立修订，旧文件保留；改变证据集合会产生另一份素材身份。
- 相同目标文件被人工改过时拒绝覆盖，可下载新预览后人工合并。
- 原始历史只读。常见密钥和 home 路径标识会过滤，仍需人工检查其他隐私。
- 继承已有证据能力边界：CBC、mcode 以及可解码的 AGY/ZCode 快照已接入，其他不支持的来源明确拒绝；不绕过修订检查，超限明确拒绝。
- Linux 本地链路已验证；U1 已取消，仍不将工程验证表述为独立用户试用，也未验证微信线上投递。
