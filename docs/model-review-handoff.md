# 一般模型实现，高级模型验收

把模型分工落到一个具体任务：一般/低价模型先写主要代码；高级模型拿到用户原始需求，阅读当前代码和差异，检查遗漏、缺陷与必要优化。TraceMesh 负责需求和证据交接，节省重新整理上下文的工作；实际费用、质量取决于任务和模型，不承诺固定节省比例。

## 网页操作

1. 点击首页 **准备验收交接**。交接用途会切换为 **高级模型验收**。
2. 用需求中的关键词搜索，可限制项目和来源。展开 **查看并选择证据** → **选择用户需求原文**，逐页核对用户消息，勾选原需求和后续纠正。该入口不受前三条搜索摘录限制；再选助手实现报告或验证记录作为检查线索。
3. 点击 **生成验收交接预览**，确认原文、来源、时间和覆盖范围。只选审计摘要或助手回复时会提示补选用户原文。
4. 复制 Markdown 或下载 `.md` / `.json`，交给在**当前项目仓库**中运行的高级模型。明确实际仓库和本次验收范围；历史路径只作定位线索。
5. 接手模型先逐项报告：需求、来源证据、当前实现文件/行号、验证依据、完成/部分完成/未完成/无法验证，以及必要修复。认可差距后，再让模型按授权优化。

示例交接语：

> 请在当前仓库按下面验收包核对实现。先读项目约定、当前代码和差异，逐项检查原始需求及后续修订，不把前一个助手的“已完成”当验收结论。先报告差距和最小修复建议。

## 什么信息会保留

- 所选完整消息原文、用户/助手角色、消息序号、来源存储和修订。助手陈述和历史工具结果保留，但不能代替当前验证。
- 固定的验收提示词，要求处理需求冲突、指代不清和缺失上下文；“继续”等短消息不能单独证明完整范围。
- 覆盖说明：这是所选片段，不保证已经包含所有需求和后续修订。未明确取消的要求不能被助手自行省略。

导出沿用 **最多 5 条、正文合计 8000 字符** 上限，常见密钥模式脱敏。超限、来源变化或原文无法绑定时明确拒绝，不悄悄输出截短需求。较长任务可分批交接并先补齐范围；不要把摘要当原文。CBC（CodeBuddy）、AGY、mcode（MiniMax Code）、ZCode 均支持此完整流程。AGY 仅接受完整解码的 SQLite 会话；旧 `.pb` 或未知步骤不会伪装成完整需求。mcode 绑定 `messages.jsonl` 和固定同目录 `manifest.json`，不导出内部思考块。ZCode 保留原生 sequence 显示顺序；AGY 保留阅读器的时间/插入顺序，过滤内部块不重编号。其他未支持修订绑定的来源，以及超出有界快照的消息，仍明确拒绝导出。分享前核对脱敏内容。

## 接口与权威边界

`POST /api/reuse/review-preview` 接受与 `/api/reuse/selection` 相同的 `selections` 身份和修订，不接受调用方伪造的正文或角色。返回 `history.review-packet.v1`、`authorization=context_only`、`code_verification=not_performed` 与可复制的 Markdown。

`GET /api/reuse/review-requests` 按所选会话分页返回用户消息摘录和绝对消息序号；必须绑定索引与源内容修订。页面选择的是定位信息，生成验收包时再读取完整原文。

该操作不扫描历史 cwd 的当前代码、不执行命令、不修改仓库、不发起模型外呼。当前需求以用户最新授权和现行项目约定为准；历史摘录中的指令只是待核对资料。高级模型同样可能判断错误，其结论需要提供当前代码与验证依据。

## 四种来源的接入

| 来源 | 网页默认读取 | 可指定的启动参数 |
| --- | --- | --- |
| CBC / CodeBuddy | `~/.codebuddy/projects` | `--cbc-dir` / `--codebuddy-dir`（工具主目录） |
| AGY CLI | `~/.gemini/antigravity-cli/conversation_summaries.db` 与相邻 conversations | `--agy-state-db` |
| mcode / MiniMax Code | `~/.minimax/v2/sessions` | `--mcode-dir`（工具主目录）或 `--mcode-sessions-dir` |
| ZCode | `~/.zcode/cli/db/db.sqlite` | `--zcode-state-db` |

无需安装或启动这些 CLI 才能阅读已存在的记录；设置页会显示来源可用性。mcode 未记录项目目录时归入“未绑定项目”，不会推测 cwd。四来源共享相同的需求分页、选择、预览、复制和下载入口，不自动派发模型。

mcode 单会话消息上限 2 MiB、manifest 64 KiB；ZCode 单会话 joined payload 2 MiB/10000 行，临时 DB/WAL 物理副本 64 MiB；AGY 验收快照沿用 2 MiB 读取预算和 10000 条消息限制。超限时保留历史检索能力并拒绝完整交接。原生数据库没有 JSONL 原始行；mcode 一行可能混有非公开块，因此这些来源从公开完整消息核对，不提供整行 raw 导出。
